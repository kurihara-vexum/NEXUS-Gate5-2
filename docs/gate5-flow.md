# Gate5 洗い出しと補完フロー

この文書は、提出された「NEXUS Gate5 例外系洗い出し表」と貸出・返却フロー図の集計をREADMEから参照しやすくしたものです。

## 8観点・20項目

| 観点 | No | 洗い出した項目 |
| --- | --- | --- |
| 1. 在庫・状態 | 1、3 | 貸出中端末、貸出可能端末0件 |
| 2. 人の状態 | 2、4 | 休職・退職者、貸出台数上限 |
| 3. 重複・多重 | 5、6、7 | 重複申請、同時競合、ブラウザバック再送 |
| 4. 入力値 | 8〜15 | 過去日、遠すぎる日付、存在しない日、当日、空欄、利用目的の空欄・超過・特殊文字 |
| 5. 順序 | 16 | 借りていない端末の返却 |
| 6. 時間 | 17 | 延滞中ユーザーの新規貸出 |
| 7. 失敗時 | 18、19 | 複数テーブル更新失敗、DB接続断・タイムアウト |
| 8. 不正操作 | 20 | 他人IDによる実行 |

## 補完後フローの判断数

正常系の元図にはひし形がありません。提出された補完図では次の16個が追加されています。

### 貸出側: 14個

1. 貸出可能端末が存在するか
2. 必須項目を入力済みか
3. 日付は実在するか
4. 返却日は明日以降か
5. 返却日は本日から1か月以内か
6. 利用目的は100文字以内か
7. 使用可能文字のみか
8. 本人のIDか
9. `employment_status = ACTIVE` か
10. 延滞中ではないか
11. 貸出台数は上限未満か
12. 重複申請ではないか
13. `status = AVAILABLE` か
14. DB更新は成功したか

### 返却側: 2個

1. `status = LENT` か
2. DB更新は成功したか

合計は16個です。
